### 3.2 Audio-Übersetzungen (Voice Cues, 25 Sprachen)

**Approach:** Python-Skript mit ElevenLabs-API – vollautomatisiert, reproduzierbar, versionierbar.

- [ ] ElevenLabs-Account anlegen, API-Key sichern (nicht ins Repo)
- [ ] Voice-Skripte verfassen (Englisch als Master, dann per DeepL in alle Sprachen)
  - [ ] Phase-Labels (Einatmen, Ausatmen, Halten, …)
  - [ ] Pattern-Beschreibungen (kurz, für Onboarding)
  - [ ] Onboarding-Erklärungen
- [ ] Python-Skript entwickeln (`scripts/generate_audio.py`)
  - [ ] Input: Skript-CSV (text, language, filename)
  - [ ] Output: MP3/OGG-Assets in `assets/audio/{lang}/`
  - [ ] ElevenLabs-Voice pro Sprache konfigurierbar (Stimme pro Sprache wählen)
  - [ ] Idempotent: bereits generierte Files nicht neu erzeugen (Cost-Kontrolle)
  - [ ] Dry-run-Modus: zeigt was generiert würde ohne API-Calls
- [ ] Skript ins Repo committen (`scripts/`), API-Key bleibt in `.env` (gitignored)
- [ ] Audio-Assets als sprachspezifische Bundles in `pubspec.yaml` organisieren
- [ ] On-demand Download pro Sprache implementieren (verhindert App-Größen-Explosion)
  - [ ] Englisch wird mitgeliefert (Fallback)
  - [ ] Andere Sprachen werden beim ersten Start in der jeweiligen Sprache heruntergeladen
- [ ] Fallback: Falls Download schlägt fehl → Englisch
- [ ] Tests: korrektes Asset wird für Gerätesprache geladen
