## Was wurde geändert?

Phase 0.7 liefert den **Disclaimer-Screen**: Ein einmaliger Hinweis-Screen erscheint beim ersten App-Start. Der Nutzer muss aktiv zustimmen, bevor die App zugänglich ist. Die Zustimmung wird versioniert in `shared_preferences` gespeichert und bei wesentlichen Textänderungen erneut eingeholt.

---

## 1. `DisclaimerRepository` (`disclaimer_repository.dart`)

Einzige Schicht, die `shared_preferences` berührt. Kapselt den Schlüssel `disclaimer_accepted_version` und die aktuelle Version:

```dart
static const int currentVersion = 1;
static const String _key = 'disclaimer_accepted_version';

Future<bool> hasAccepted() async {
  final prefs = await SharedPreferences.getInstance();
  return (prefs.getInt(_key) ?? 0) >= currentVersion;
}
```

`hasAccepted()` vergleicht die gespeicherte Versionsnummer mit `currentVersion`. Wird `currentVersion` angehoben, sieht jeder Nutzer den Disclaimer erneut – ohne dass Code an anderer Stelle geändert werden muss.

## 2. `DisclaimerBloc`

### Events

| Event | Auslöser |
|-------|---------|
| `DisclaimerCheckRequested` | App-Start – prüft ob Zustimmung vorliegt |
| `DisclaimerAccepted` | Tap auf „I Agree"-Button |

### Status-Maschine

```
initial
  └─ DisclaimerCheckRequested ──► loading
                                    ├─ hasAccepted() == true  ──► accepted
                                    └─ hasAccepted() == false ──► notAccepted
notAccepted
  └─ DisclaimerAccepted ──► accepted  (+ persist via repository.accept())
```

`DisclaimerAccepted` ruft `repository.accept()` auf, bevor es den State emittiert – so ist die Persistierung garantiert bevor die UI wechselt.

## 3. `DisclaimerGate` + `_LoadingScreen` (`main.dart`)

Das Gate ersetzt das frühere direkte `home: BreathingSessionPage()`:

```dart
BlocProvider(
  create: (_) => DisclaimerBloc(repository: DisclaimerRepository())
    ..add(const DisclaimerCheckRequested()),
  child: BlocBuilder<DisclaimerBloc, DisclaimerState>(
    builder: (context, state) => switch (state.status) {
      DisclaimerStatus.accepted    => const BreathingSessionPage(),
      DisclaimerStatus.notAccepted => const DisclaimerPage(),
      _                            => const _LoadingScreen(),
    },
  ),
)
```

Der `initial`- und `loading`-State zeigen einen leeren `_LoadingScreen` (weißer/dunkler Background + `CircularProgressIndicator`). Da `SharedPreferences` typischerweise in < 10 ms antwortet, ist dieser Screen in der Praxis kaum sichtbar.

## 4. `DisclaimerPage` (`disclaimer_page.dart`)

### Layout

```
Scaffold
└─ SafeArea
   └─ Center (für Tablet/Desktop-Zentrierung)
      └─ ConstrainedBox(maxWidth: 600 auf Expanded-Breakpoint)
         └─ Padding
            ├─ Expanded → SingleChildScrollView → _DisclaimerBody
            └─ _AcceptButton (fixe Höhe 52 px, am unteren Rand)
```

`Breakpoints.isExpanded()` stellt die 600-px-Beschränkung her — dieselbe Klasse wie in Phase 0.6. Auf Smartphones entfällt die Einschränkung (`double.infinity`).

### `_DisclaimerBody`

Titel + Einleitungstext + 4 Bullet-Points. Bullets werden per `.map()` aus einer Liste von l10n-Strings erzeugt; der Bullet-Punkt selbst ist in `colors.accent` gefärbt, der Fließtext in `colors.textSecondary`.

### `_AcceptButton`

Leaf-Widget, empfängt `onPressed` als `VoidCallback` — kein direkter BLoC-Zugriff gemäß Schichtenregel. Zugriff auf `DisclaimerBloc` findet ausschließlich in `DisclaimerPage.build()` statt.
