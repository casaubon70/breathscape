/// Internes Event – wird ausschließlich vom Ticker im BreathingBloc gefeuert.

  final Duration delta;

  @override
  List<Object?> get props => [delta];

## 3. API-Änderungen

### `BreathingEvent`

- Basisklasse: `abstract class` → `sealed class`. Pattern-Matching auf Subtypen ist nun exhaustiv. Subklassen können nur innerhalb derselben Library definiert werden.
- Alle Subklassen: `class` → `final class`. Subklassing von außen nicht mehr möglich.
- `BreathingEvent.props` ist jetzt explizit definiert (`[]`), vorher nicht überschrieben.
- `BreathingTickUpdated.props` ist jetzt explizit definiert (`[delta]`), vorher nicht überschrieben.
- `PlayPressed`, `PausePressed`, `ResetPressed`, `PhaseCompleted`: Explizite `const`-Konstruktoren. Vorher fehlten diese.

### `BreathingState`

- Klasse: `class` → `final class`. Subklassing von außen nicht mehr möglich.

### `BreathingAnimationWidget`

- Klasse: `class` → `final class` (implizit durch Konstruktor-Reihenfolge, nicht durch Klassendeklaration — die Klassendeklaration bleibt `class BreathingAnimationWidget`).

**Hinweis:** Die Parameterreihenfolge im Konstruktor hat sich geändert (`super.key` an letzter Stelle). Da alle Parameter benannt sind, hat dies keine Auswirkung auf bestehende Aufrufstellen.

### `PlaybackControls`

- Parameterreihenfolge: `super.key` an letzter Stelle. Kein Einfluss auf benannte Aufrufstellen.
- `crossAxisAlignment: CrossAxisAlignment.center` entfernt. Das Verhalten ändert sich nicht (war Default).

// Nachher:
