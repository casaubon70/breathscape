## Was wurde geändert?

Das Inkrement fügt eine Pattern-Auswahl hinzu: Statt eines fest verdrahteten Patterns lädt die App beim Start drei Atemtechniken aus einem YAML-Asset und zeigt sie in einem Dropdown an. Domain-Modelle wurden um Equatable und YAML-Parsing erweitert. Der BLoC-State trägt jetzt das aktuell gewählte Pattern und die verbleibenden Sekunden der laufenden Phase. Die Animations-Widget-Schnittstelle wurde um zwei Bool-Flags erweitert, die steuern ob die Kreis-Ornamente sichtbar sind.

## Datenmodell

### `breathing_phase.dart` — `BreathingPhase`

```dart
import 'package:equatable/equatable.dart';

enum PhaseType { inhale, holdIn, exhale, holdOut }

class BreathingPhase extends Equatable {
  const BreathingPhase({required this.type, required this.duration});

  factory BreathingPhase.fromMap(Map<dynamic, dynamic> map) {
    return BreathingPhase(
      type: _typeFromString(map['type'] as String),
      duration: Duration(seconds: map['seconds'] as int),
    );
  }

  final PhaseType type;
  final Duration duration;

  static PhaseType _typeFromString(String value) {
    return switch (value) {
      'inhale'   => PhaseType.inhale,
      'hold_in'  => PhaseType.holdIn,
      'exhale'   => PhaseType.exhale,
      'hold_out' => PhaseType.holdOut,
      _          => throw ArgumentError('Unknown phase type: $value'),
    };
  }

  @override
  List<Object> get props => [type, duration];
}
```

`BreathingPhase` erweitert nun `Equatable`. Die Factory `fromMap` parst einen YAML-Map-Eintrag: `type` wird via Switch auf `PhaseType` gemappt, `seconds` wird zu `Duration` konvertiert.

### `breathing_pattern.dart` — `BreathingPattern`

```dart
import 'package:breathscape/features/breathing_session/domain/breathing_phase.dart';
import 'package:equatable/equatable.dart';

class BreathingPattern extends Equatable {
  const BreathingPattern({required this.name, required this.phases});

  factory BreathingPattern.fromMap(Map<dynamic, dynamic> map) {
    final rawPhases = map['phases'] as List<dynamic>;
    return BreathingPattern(
      name: map['name'] as String,
      phases: rawPhases
          .cast<Map<dynamic, dynamic>>()
          .map(BreathingPhase.fromMap)
          .toList(),
    );
  }

  final String name;
  final List<BreathingPhase> phases;

  @override
  List<Object> get props => [name, phases];
}
```

Neu: `Equatable`, Factory `fromMap`. Der `name`-Vergleich via `props` erlaubt das Matchen des Dropdown-Werts gegen das selektierte Pattern im State.

## BLoC: States

### Neue Felder in `BreathingState`

| Feld | Typ | Default | Bedeutung |
|---|---|---|---|
| `selectedPattern` | `BreathingPattern` | — (required) | Das aktuell gewählte Pattern. Steuert die Dropdown-Anzeige und die Kreis-Sichtbarkeit. |
| `phaseSecondsRemaining` | `int` | `0` | Verbleibende ganze Sekunden in der aktuellen Phase (Ceiling). Wird bei jedem Ticker-Tick emittiert. |

`selectedPattern` ist ein required-Parameter des Konstruktors — ein `BreathingState` ohne Pattern kann nicht konstruiert werden.

## Signalwege

### Pattern-Wechsel via Dropdown

**Nutzer öffnet Dropdown → wählt Pattern → `PatternSelected(pattern)` → `_onPatternSelected` → Ticker gestoppt, `_pattern` überschrieben, alle Phasen-Counter zurückgesetzt → `BreathingState(selectedPattern: pattern, phaseSecondsRemaining: pattern.phases.first.duration.inSeconds)` → `_PatternDropdown` rebuilt mit neuem `value`, `BreathingAnimationWidget` rebuilt mit neuen `showTopCircle`/`showBottomCircle`-Werten**

`_onPatternSelected` in `breathing_bloc.dart`: stoppt `_ticker`, setzt `_pattern`, `_phaseIndex`, `_phaseAccumulated`, `_lastTickElapsed` zurück und emittiert einen frischen `BreathingState` mit dem neuen Pattern.

### Sekunden-Countdown pro Ticker-Tick

**Ticker-Callback `_onTick` → `BreathingTickUpdated(delta)` → `_onTickUpdated` → `_secondsRemaining()` berechnet verbleibende Mikrosekunden, ceil zu int → `copyWith(phaseSecondsRemaining: ...)` emittiert → `BlocBuilder` rebuilt → `'${state.phaseSecondsRemaining}s'` in der UI aktualisiert**

`_secondsRemaining()` in `breathing_bloc.dart`:
```dart
int _secondsRemaining() {
  final duration = _pattern.phases[_phaseIndex].duration;
  final remaining = duration - _phaseAccumulated;
  return (remaining.inMilliseconds / 1000)
      .ceil()
      .clamp(0, duration.inSeconds);
}
```

Beim Phasenwechsel innerhalb von `_onTickUpdated` wird `_phaseAccumulated` auf `Duration.zero` zurückgesetzt bevor `_secondsRemaining()` aufgerufen wird — der Wert zeigt dann die volle Dauer der neuen Phase.

### Kreis-Sichtbarkeit nach Pattern

**Pattern geladen / gewechselt → `state.selectedPattern.phases` → `.any((p) => p.type == PhaseType.holdIn)` / `.any((p) => p.type == PhaseType.holdOut)` in `breathing_session_page.dart` → `showTopCircle` / `showBottomCircle` an `BreathingAnimationWidget` übergeben → `Opacity(opacity: show ? 1.0 : 0.0)` um den jeweiligen Kreis**

Die Berechnung findet direkt im `BlocBuilder`-Body der Page statt. Das Widget selbst empfängt nur `bool`-Primitives.

## Datenströme

### YAML → Domain → State

1. `PatternsRepository.load()` (statische Methode) ruft `rootBundle.loadString('assets/breathing_patterns.yaml')` auf.
2. Der YAML-String wird via `loadYaml(raw) as YamlMap` geparst.
3. `doc['patterns'] as YamlList` wird via `.cast<Map<dynamic, dynamic>>().map(BreathingPattern.fromMap)` in `List<BreathingPattern>` überführt.
4. `_BreathingSessionPageState.initState` speichert den resultierenden `Future<List<BreathingPattern>>` in `_patternsFuture`.
5. Der `FutureBuilder` in `build` übergibt `patterns.first` an `BreathingBloc(pattern: patterns.first)` und die vollständige Liste an `_BreathingSessionView(patterns: patterns)`.

### Pattern-Liste → Dropdown → BLoC

Die `patterns`-Liste fließt von der Page als Konstruktorparameter in `_BreathingSessionView` und von dort in `PatternDropdown`. Der `PatternDropdown`-Widget liest `state.selectedPattern` via `BlocBuilder` um den aktiven Dropdown-Wert zu kennen, und dispatcht `PatternSelected` an den BLoC via `context.read`.

## UI

### `PatternDropdown` (neu, `presentation/widgets/pattern_dropdown.dart`)

`StatelessWidget`. Empfängt `List<BreathingPattern> patterns`. Registriert via `BlocBuilder` nur auf `selectedPattern`-Änderungen (`buildWhen`). Rendert einen `DropdownButton<BreathingPattern>` mit `Align(alignment: Alignment.centerLeft)`. Dropdown ist immer aktiv — auch während einer laufenden Session; ein Wechsel stoppt die Session. Unterline ist via `SizedBox.shrink()` ausgeblendet.

### `BreathingAnimationWidget` — neue Parameter

`showTopCircle` (bool, default `true`) und `showBottomCircle` (bool, default `true`). Jeder Kreis ist in `Opacity(opacity: show ? 1.0 : 0.0)` eingewickelt — der Platz bleibt erhalten, der Kreis wird transparent. Der Wert wird in `breathing_session_page.dart` aus `state.selectedPattern.phases` berechnet.

### Sekunden statt Zykluszähler

`'Cycle ${state.currentCycle}'` wurde durch `'${state.phaseSecondsRemaining}s'` ersetzt. Der Wert zählt von der vollen Phasendauer auf 0 herunter (Ceiling-Rundung).

### `BreathingSessionPage` → `StatefulWidget`

Die Page ist nun ein `StatefulWidget`. `initState` startet `PatternsRepository.load()` einmalig und hält den Future in `_patternsFuture`. Der `FutureBuilder` zeigt während des Ladens einen `CircularProgressIndicator` und nach Abschluss den vollständigen `BlocProvider`+View-Tree. Das Laden dauert in der Praxis unter eine Render-Frame, da `rootBundle` das Asset gecacht hält.
