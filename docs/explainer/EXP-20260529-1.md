## Was wurde geändert?

Dieses Inkrement führt die **Extended Exhale**-Funktion ein: Auf konfigurierbaren Zyklen wird das normale Ausatmen durch ein tieferes, längeres Ausatmen ersetzt, das auch den unteren Reservebereich des Rechtecks leert. Das darauffolgende Einatmen startet nahtlos vom untersten Punkt der Animation aus. Außerdem wurde ein neues **CycleDotRow**-Widget ergänzt und sieben Bugs aus einem Code-Review behoben.

---

## Datenmodell

### `PhaseType` – neuer Wert `extendedExhale`

```dart
enum PhaseType { inhale, holdIn, exhale, extendedExhale, holdOut }
```

`extendedExhale` taucht **nicht** in der YAML auf. Er wird zur Laufzeit vom BLoC substituiert, wenn die aktuelle Zyklusnummer durch `extendedExhaleInterval` teilbar ist. Die YAML kennt nur `exhale`; der BLoC baut daraus eine synthetische Phase mit `duration + 2s`.

### `BreathingPattern` – neues Feld `extendedExhaleInterval`

```dart
class BreathingPattern extends Equatable {
  const BreathingPattern({
    required this.name,
    required this.phases,
    this.defaultCycles = 10,
    this.extendedExhaleInterval,   // neu
  });

  /// Every Nth cycle uses an extended exhale (exhale + 2 s). Null = disabled.
  final int? extendedExhaleInterval;

  @override
  List<Object?> get props => [name, phases, defaultCycles, extendedExhaleInterval];
}
```

YAML-Key: `extended_exhale_interval`. Fehlt der Key, ist der Wert `null` (Feature deaktiviert). Konfigurierte Patterns:
- **Box Breathing**: `extended_exhale_interval: 3` → jeder 3. Zyklus
- **Coherent Breathing**: `extended_exhale_interval: 5` → jeder 5. Zyklus
- **Test Deep-Exhale**: `extended_exhale_interval: 1` → jeder Zyklus (Testpattern)

### `BreathingState` – neues Feld `deepZoneFill`, `isExtendedExhale` als Getter

```dart
final class BreathingState extends Equatable {
  // ...
  final double deepZoneFill;      // 0.0–1.0: wie viel der unteren Zone gefüllt ist

  bool get isExtendedExhale =>    // abgeleitet – kein gespeichertes Feld
      currentPhase == PhaseType.extendedExhale;
}
```

`deepZoneFill` steuert im Widget den hellblauen Overlay im unteren surfaceDim-Bereich. `isExtendedExhale` wurde von einem gespeicherten `bool`-Feld zu einem Computed Getter umgewandelt, um Divergenz zwischen `currentPhase` und dem Flag auszuschließen.

## BLoC

### Phasen-Substitution: `_effectivePhase`

```dart
BreathingPhase _effectivePhase(int phaseIndex, int cycle) {
  final phase = _pattern.phases[phaseIndex];
  final interval = _pattern.extendedExhaleInterval;
  if (phase.type == PhaseType.exhale &&
      interval != null && interval > 0 &&
      cycle > 0 && cycle % interval == 0) {
    return BreathingPhase(
      type: PhaseType.extendedExhale,
      duration: phase.duration + const Duration(seconds: 2),
    );
  }
  return phase;
}
```

Wird an **jeder** Stelle aufgerufen, die Phasendauer oder -typ braucht: Tick-Loop, Sekunden-Countdown, Session-Gesamt-Countdown.

### Animationsberechnung

Zwei räumliche Schwellenwerte – abgeleitet aus den Widget-Flex-Werten (mittlere Zone flex:6, untere Zone flex:2):

```dart
static const double _kExtendedExhaleThreshold = 6.0 / (6.0 + 2.0); // 0.75
static const double _kDeepInhaleThreshold = 1.0 - _kExtendedExhaleThreshold; // 0.25
```

**Extended Exhale** (progress 0 → 1 über die gesamte Dauer, z.B. 6 s):
- `progress 0 → 0.75`: `fillLevel` 1.0 → 0.0 (mittlere Zone leert sich gleichmäßig)
- `progress 0.75 → 1.0`: `fillLevel = 0`, `deepZoneFill` 0.0 → 1.0 (untere Zone füllt sich)
- `circleOpacity` (oberer Kreis): faded von 0 → 1 über die ersten 75%
- `circleBottomOpacity` (unterer Kreis): faded von 1 → 0 während die untere Zone füllt (75%–100%)

**Deep Inhale** (Einatmen nach einem extended exhale, progress 0 → 1):
- `progress 0 → 0.25`: `deepZoneFill` 1.0 → 0.0 (untere Zone leert sich aufwärts)
- `progress 0.25 → 1.0`: `fillLevel` 0.0 → 1.0 (mittlere Zone füllt sich aufwärts)
- Gleichmäßige Pixel-Geschwindigkeit in beiden Zonen durch den räumlichen Threshold

### `_startFromDeep`-Flag

Privates BLoC-Feld, das den Übergang von Extended Exhale zum nächsten Einatmen steuert:

```
extendedExhale endet → _startFromDeep = true
holdOut (falls vorhanden) → deepZoneFill bleibt 1.0
inhale startet → Deep-Inhale-Animation
inhale endet → _startFromDeep = false
```

Gesetzt/gelöscht in `_updateStartFromDeep(endingPhase)`. Bei Reset, Pattern-Wechsel und `_onPlayPressed` (idle) wird es explizit auf `false` gesetzt.

### Session-Countdown-Fix

`_sessionSecondsRemaining` und `_calcTotalSessionSeconds` berücksichtigen jetzt die +2 s pro Extended-Exhale-Zyklus:

```dart
int _sessionSecondsRemaining(int currentCycle) {
  var total = _secondsRemaining(currentCycle);
  for (var i = _phaseIndex + 1; i < _pattern.phases.length; i++) {
    total += _effectivePhase(i, currentCycle).duration.inSeconds;
  }
  for (var c = currentCycle + 1; c <= _pattern.defaultCycles; c++) {
    for (var i = 0; i < _pattern.phases.length; i++) {
      total += _effectivePhase(i, c).duration.inSeconds;
    }
  }
  return total;
}
```

### Tick-Overshoot-Fix

```dart
// Vorher (Drift): Overshoot wird verworfen

// Nachher (korrekt): Overshoot in die nächste Phase übertragen
```

## Widget-Änderungen

### `BreathingAnimationWidget` – `deepZoneFill`-Parameter

```dart
class BreathingAnimationWidget extends StatelessWidget {
  const BreathingAnimationWidget({
    // ...
    this.deepZoneFill = 0.0,
  });

  final double deepZoneFill;
}
```

Wenn `deepZoneFill > 0`, wird ein hellblauer (`colors.accent`) Overlay von oben in den unteren surfaceDim-Bereich gerendert:

```dart
Flexible(
  flex: 2,
  child: Stack(
    children: [
      Container(color: colors.surfaceDim),
      if (deepZoneFill > 0.0)
        Align(
          alignment: Alignment.topCenter,
          child: FractionallySizedBox(
            heightFactor: deepZoneFill.clamp(0.0, 1.0),
            child: Container(color: colors.accent),
          ),
        ),
    ],
  ),
),
```

### `CycleDotRow` – neues Widget

```dart
class CycleDotRow extends StatelessWidget {
  const CycleDotRow({
    required this.totalCycles,
    required this.currentCycle,
    this.extendedExhaleInterval,
  });

  static const double dotLarge = 10; // public für Layout-Berechnung in der Page
}
```

- Je ein Dot pro Zyklus, als `Wrap` (bricht bei vielen Zyklen automatisch um)
- Extended-Exhale-Zyklen: `colors.signal` (Amber)
- Normale Zyklen: `colors.accent` mit 35% Opacity
- Aktueller Zyklus: volle Opacity + 10 px Durchmesser (andere: 6 px)
- Wird am unteren Rand des `Expanded`-Bereichs gepinnt, mit eigenem `BlocBuilder` (`buildWhen` auf Cycle- und Pattern-Änderung)

**Layout**: `dotsAreaHeight = CycleDotRow.dotLarge + spacing.m` — kein Magic Number, koppelt sich an Widget- und Theme-Konstanten.
