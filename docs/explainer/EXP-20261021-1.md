## UI

### `BreathingSessionPage` → `_BreathingSessionView` (`breathing_session_page.dart`)

Im `LayoutBuilder` des mittleren `Expanded` wird `_buildSessionArea(...)` jetzt von einem `FittedBox` umschlossen:

```dart
Expanded(
  child: Center(
    // animHeight is a heuristic; on short windows the
    // labels + circles + bar exceed the space, so
    // scale down instead of overflowing.
    child: FittedBox(
      fit: BoxFit.scaleDown,
      child: _buildSessionArea(
        context,
        constraints,
        animHeight,
      ),
    ),
  ),
),
```

`animHeight` wird weiterhin als `((constraints.maxHeight - dotsAreaHeight) * 0.40).clamp(130.0, isExpanded ? 500.0 : 300.0)` berechnet. Der Sitzungsbereich (Phasen-Label, Sekunden-Countdown, `BreathingAnimationWidget`, `VoiceMuteButton`) wird in dieser Größe aufgebaut. Laut Commit-Message braucht der gerenderte Stapel etwa das 1,75-fache von `animHeight` plus feste Abstände und lief bei Fensterhöhen unter ca. 600 px über. Mit `BoxFit.scaleDown` wird der Bereich nur dann proportional verkleinert, wenn er nicht in den verfügbaren Platz passt; sonst bleibt er unskaliert.

Die `BlocBuilder` innerhalb von `_buildSessionArea` und ihre `buildWhen`-Bedingungen sind unverändert. Die Reaktion auf State-Änderungen bleibt gleich, nur die Darstellungsgröße kann sich ändern.
